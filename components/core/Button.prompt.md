Uppercase-label button in four variants for the Dysobay storefront: ink-filled primary, outlined secondary, clay-filled accent (rare, for "Shop the Drop" moments), and underline ghost for tertiary links.

```jsx
<Button variant="accent" size="lg">Add to Bag</Button>
```

Variants: `primary` (ink fill), `secondary` (outline), `accent` (clay fill, use sparingly), `ghost` (underlined text link). Sizes: `sm`, `md`, `lg`.
